Installation d'une machine virtuel pour tester

Pour tester la configuration, j'ai utilisé une machine virtuelle avec VirtalBox.

Pour la configuration de la VM :

son nom test-nas et un Linux 64bits

Pour le hardware : 8 Go de RAM et 4 processeurs. On commence avec, on pourra modifier les paramètre après.

Je donne 30 Go de disque.

Je modifie la configuration réseau, avec Accès par pont (bridge) et j'active le mode promiscuité. Pour que la VM soit configuré comme une machine sur le réseau local.

Je démarre l'installation de NixOS:

Je prends les options par défaut sauf pour le bureau, ou je choisis no desktop.

Je lance l'installation. Rien de particulier, on est sur du NixOS.

Une fois que la machine est installée. On démarre la VM, et on se connecte dessus en root.

On édite le fichier /etc/nixos/configuration.nix

On vérifie que le SSH est bien installé. Pour cela, on vérifie que cette ligne est bien présente et non commenter.

{
  services.openssh.enable = true;
}

Si on veut se connecter en root depuis ssh avec un mot de passe, on ajoute :

{
  services.openssh.settings.PermitRootLogin = "yes";
}

Autre modification le réseau :

On commente (ou on la supprime) cette ligne pour déactiver networkmanager.

  # networking.networkmanager.enable = true;

On force une op fixe sur le réseau, ici : 192.168.0.201. C'est plus pratique.

{
  networking.interfaces = {
    enp0s3 = {
      ipv4 = {
        addresses = [
          {
            address = "192.168.0.201";
            prefixLength = 24;
          }
        ];
      };
      useDHCP = true;
    };
  };
}

On édite /etc/nixos/hardware-configuration.nix pour vérifier que les ajouts d'invité VirtualBox sont bien installées.

{
  virtualisation.virtualbox.guest.enable = true;
}

On applique la configuration avec cette commande. (option --upgrade-all permet de faire la mise a jour)

nixos-rebuild switch --upgrade-all

On arrête la machine :

halt -p

Pour la configuration, je crée un répertoire pour y placer tous les différentes configurations qui seront partager entre la VM et machine de prod. Je crée un nouveau sous-répetoire nix, que je partage un sur VM. Je la monte dans /etc/nixos/config

Dans le répertoire, je crée un fichier main.nix avec :

{ config, pkgs, ...}:
{
  imports = [

  ];
}

Je crée un second fichier vars.nix pour placer les variables qui seront partager dans la config :

{
  ip = "192.168.0.201"; # on placer la valeur de l'ip
}

Pour démarrer la VM, j'utilise la commande :

VBoxManage startvm test-nas --type headless

Cela permet de lancer la VM sans fenêtres.

Normalement, si tout fonctionne, après quelle seconde, on peut se connecter en SSH

ssh user@192.168.0.201

On édite le fichier /etc/nixos/configuration.nix

{ config, pkgs, ...}:
let # entre let et in on définie les variables
  vars = import ./config/vars.nix;
in
{
  imports =
    [ # Include the results of the hardware scan.
      ./hardware-configuration.nix
      ./config/main.nix # on doit ajouter cette ligne pour que le fichier main fait soit utilisé.
    ];

  networking.interfaces = {
    enp0s3 = {
      ipv4 = {
        addresses = [
          {
            address = vars.ip; # on utilise la variable ip
            prefixLength = 24;
          }
        ];
      };
      useDHCP = true;
    };
  };
  ...
}

La machine est prête.
