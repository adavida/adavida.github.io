Installation de OpenLDAP

Je souhaite avoir un nom utilisateur et mot de passe qui soit partagé entre les différents services que je souhaite installer. La solution que j’ai choisie est utilisée OpenLDAP.
Parmi les alternatives, que j’ai regardé, lldap, il est plus simple à utiliser et à installer, il fournit une interface pour gérer les utilisateurs, mais pendant mes premiers essais, il ne gérait pas l’intégration avec Linux sur la version stable.

Je me suis basé sur la page du wiki.

Je ne vais pas expliquer le fonctionnement du protocole LDAP, je vais juste expliquer comment installer un serveur openldap avec nixos et controller qu'il fonctionne.

Installation sans chiffrement

Pour commencer, je crée un fichier openldap.nix, avec :

{ config, pkgs, ... }:
  let
    vars = import ./vars.nix;
  in
{
 services.openldap = {
    enable = true;

    /* enable plain connections only */
    urlList = [ "ldap:///" ];


    settings = {
      attrs = {
        olcLogLevel = "conns config";
      };

      children = {
        "cn=schema".includes = [
          "${pkgs.openldap}/etc/schema/core.ldif"
          "${pkgs.openldap}/etc/schema/cosine.ldif"
          "${pkgs.openldap}/etc/schema/inetorgperson.ldif"
          "${pkgs.openldap}/etc/schema/nis.ldif"
        ];

        "olcDatabase={1}mdb".attrs = {
          objectClass = [ "olcDatabaseConfig" "olcMdbConfig" ];

          olcDatabase = "{1}mdb";
          olcDbDirectory = "/var/lib/openldap/data";

          olcSuffix = vars.base_dn;

          /* your admin account, do not use writeText on a production system */
          olcRootDN = "cn=admin,${vars.base_dn}";
          olcRootPW.path = pkgs.writeText "olcRootPW" "pass";

          olcAccess = [
            /* custom access rules for userPassword attributes */
            ''{0}to attrs=userPassword
                by self write
                by anonymous auth
                by * none''

            /* allow read on anything else */
            ''{1}to *
                by self read
                by * read''
          ];
        };
      };
    };
  };
}

Je l’ajoute dans le fichier main.nix

{ config, pkgs, ... }:
{
  imports = [
    ./coredns.nix
    ./openldap.nix
  ];
}

Et j’ajoute dans vars.nix la variable base_dn

{
  ip = "192.168.0.201";
  base_host = "test-nas.local";
  base_dn = "DC=test-nas,DC=local";
}

Enfin, je rebuild le système avec :

nixos-rebuild switch

Si tout fonctionne sur la machine, on peut tester avec

ldapsearch -w pass -H ldap://127.0.0.1:389 -D "cn=admin,dc=test-nas,dc=local" -b "cn=admin,dc=test-nas,dc=local"

Cela lance la une recherche dans l’annuaire. L’option : -w, c’est pour passer le mot de passe et l'option : -D, le Distinguished Name (identifiant unique) sur lequel on lance la recherche.

Pour pouvoir tester tous les postes sur le réseau, on ouvre les ports en ajoutant dans le fichier openldap.nix

  { config, pkgs, ... }:
    let
      vars = import ./vars.nix;
    in
  {
    # ouverture du ports 389
    networking.firewall.allowedTCPPorts = [ 389 ];

    services.openldap = {
        # ...
    };
  }
ldapsearch -w pass -H ldap://{ip-de-la-machine}:389 -D "cn=admin,dc=test-nas,dc=local" -b "cn=admin,dc=test-nas,dc=local"

On peut aussi utiliser des outils graphiques, moi, j'utilise apache directory studio

Attention le port 389 n’est pas chiffré, toutes les informations passent en claire sur le réseau.

SSL

Je pars que vous possédiez les certificats, vous trouvez ici comment crée un certificat autosigné

On aura besoin :

  • le certificat racine : "/etc/nixos/secret/certs/homeCA.crt";
  • le certificat du ldap : "/etc/nixos/secret/certs/ldap.crt";
  • la clée privée du certificat du ldap : "/etc/nixos/secret/certs/ldap.key"
{ config, pkgs, ... }:
  let
    vars = import ./vars.nix;
  in
{
  # le port ldaps est 636
  networking.firewall.allowedTCPPorts = [ 636 ];

  services.openldap = {
    enable = true;

    # on change ici de ldap à ldaps
    urlList = [ "ldaps:///" ];


    settings = {
      attrs = {
        olcLogLevel = "conns config";

        # on ajoute les informnation
        olcTLSCACertificateFile = "/etc/nixos/secret/certs/homeCA.crt";
        olcTLSCertificateFile = "/etc/nixos/secret/certs/ldap.crt";
        olcTLSCertificateKeyFile = "/etc/nixos/secret/certs/ldap.key";
        olcTLSCipherSuite = "HIGH:MEDIUM:+3DES:+RC4:+aNULL";
        olcTLSCRLCheck = "none";
        olcTLSVerifyClient = "never";
        olcTLSProtocolMin = "3.1";
      };

      children = {
        "cn=schema".includes = [
          "${pkgs.openldap}/etc/schema/core.ldif"
          "${pkgs.openldap}/etc/schema/cosine.ldif"
          "${pkgs.openldap}/etc/schema/inetorgperson.ldif"
          "${pkgs.openldap}/etc/schema/nis.ldif"
        ];

        "olcDatabase={1}mdb".attrs = {
          objectClass = [ "olcDatabaseConfig" "olcMdbConfig" ];

          olcDatabase = "{1}mdb";
          olcDbDirectory = "/var/lib/openldap/data";

          olcSuffix = vars.base_dn;

          olcRootDN = "cn=admin,${vars.base_dn}";
          olcRootPW.path = pkgs.writeText "olcRootPW" "pass";

          olcAccess = [
            ''{0}to attrs=userPassword
                by self write
                by anonymous auth
                by * none''

            ''{1}to *
                by self read
                by * read''
          ];
        };
      };
    };
  };
}

Si tout s'est bien passée, on teste, depuis le serveur, avec la commande :

LDAPTLS_REQCERT=never ldapsearch -w pass -H ldaps://127.0.0.1 -D "cn=admin,dc=test-nas,dc=local" -b "dc=test-nas,dc=local"

LDAPTLS_REQCERT=never permet de forcer le certificat SSL à être accepté.

ldapi

Il est possible d'interroger le serveur ldap sans passer par le réseau.

Pour cela, il existe ldapi : LDAP over IPC.

On modifie openldap.nix pour qu'il utilise l'adresse ldapi:// :

{ config, pkgs, ... }:
  let
    vars = import ./vars.nix;
  in
{
  # le port ldaps est 636
  networking.firewall.allowedTCPPorts = [ 636 ];

  services.openldap = {
    enable = true;

    # on change ici de ldap à ldaps
    urlList = [
        "ldapi://"  # on ajoute cette pour activer  ldap over ipc socket on /var/run/openldap/ldapd.sock
        "ldaps:///"
      ];
  };
}

et pour tester, uniquement sur le serveur ldap :

ldapsearch -x -w pass -H ldapi:/// -D "cn=admin,dc=test-nas,dc=local" -b "dc=test-nas,dc=local"

utiliser le serveur ldap

Pour interroger openLDAP :

# depuis le serveur
ldapsearch -x -w pass \
  -H ldapi:/// \
  -D "cn=admin,dc=test-nas,dc=local" \
  -b "dc=test-nas,dc=local"
# depuis une autre machine
ldapsearch -x -w pass \
   -H ldaps://{ip du serveur} \
   -D "cn=admin,dc=test-nas,dc=local" \
   -b "dc=test-nas,dc=local" \
   -o tls_request=never

-x indique le mode authentification
-w pass: pour le mot de passe ici pass
-H ldaps://{ip du serveur} est l'adresse ip du serveur ldap
-D le root dn
-b "dc=test-nas,dc=local" est la base de recherche

Ajout d'entrée dans le openLDAP

Je crée un fichier base.ldif avec plusieurs entrées que l'on souhaite ajouté au serveur ldap.

Il est possible les rentrées dans des fichiers séparés. Attention à l'ordre ajout dans le openLDAP, à cause des dépendances.

# on crée la base
dn: dc=test-nas,dc=local
objectClass: top
objectClass: domain
dc: test-nas

# on créee pour le neoud pour la liste des utilisateur
dn: ou=users,dc=test-nas,dc=local
objectClass: organizationalUnit
ou: users

# on crée la liste la liste des groups
dn: ou=groups,dc=test-nas,dc=local
objectClass: organizationalUnit
ou: groups

# on crée le 1er utilisateur
dn: cn=user,ou=Users,dc=test-nas,dc=local
objectClass: inetOrgPerson
objectClass: posixAccount
objectClass: shadowAccount
uidNumber: 1100
gidNumber: 1000
homeDirectory: /home/user
loginShell: /bin/bash
givenName: user
sn: Adler
cn: user
displayName: display name
uid: user
mail: user@mail.com
userPassword: 1234


# on crée un groupe users
dn: cn=users,ou=groups,dc=test-nas,dc=local
objectClass: groupOfNames
cn: users
member: uid=user,ou=users,dc=test-nas,dc=local

# on crée un groupe admin
dn: cn=admin,ou=groups,dc=test-nas,dc=local
objectClass: groupOfNames
cn: admin
member: uid=user,ou=users,dc=test-nas,dc=local

Pour ajouter les entrer

ldapadd -x -w pass -H ldaps://{ip du serveur} \
  -D "cn=admin,dc=test-nas,dc=local"  \
  -o tls_reqcert=never \
  -f base.ldif

Et on a la réponse :

adding new entry "dc=test-nas,dc=local"

adding new entry "ou=users,dc=test-nas,dc=local"

adding new entry "ou=groups,dc=test-nas,dc=local"

adding new entry "cn=user,ou=Users,dc=test-nas,dc=local"

adding new entry "cn=users,ou=groups,dc=test-nas,dc=local"

adding new entry "cn=admin,ou=groups,dc=test-nas,dc=local"
