Installation de CoreDNS

Je souhaite pouvoir accéder aux services sur le NAS via une adresse : nom_du_service.nas.local.

Pour cela plusieurs solutions sont possibles :

  • Modifier le fichier hosts de toutes les machines et ajouter tous les services.
    Cela me pose comme problème :
    1. je dois modifier toutes les machines qui souhaitent les utiliser avec le service.
    2. impossible d'utiliser générique *.nas.local, à chaque nouveau service, je dois modifier toutes les machines.
  • Utiliser la diffusion des noms par le protocole mDNS, J'ai testé, c'est très limité et pas super fiable.
  • Modifier les réponses du serveur DNS, sur mon réseau, j'utilise celui fourni par la box, et il n'offre pas de possiblité.
  • Crée un serveur DNS et l'utiliser, j'ai choisi CoreDNS.

Les options de NixOS CodeDns CoreDns Manual

Dans le répertoire de partage avec la VM, je crée un fichier coredns.nix avec :

{ config, pkgs, ...}:
{
    networking.firewall.allowedUDPPorts= [ 53 ]; # ouverture du port dns dans le parfeu.

    services.coredns= {
      enable = true; # activation de CoreDns
      extraArgs = [
        "-dns.port=53"
      ];

      config = ''
        . {
            errors
            health
            ready
            forward . /etc/resolv.conf
            cache 30
            loop
            reload
            loadbalance
            log
          }
         '';
    };
}

On ajoute dans le fichier dans les imports main.nix

{ config, pkgs, ...}:
{
  imports = [
    ./coredns.nix
  ];
}

On rebuild la configuration avec la commande nixos-rebuild switch.

Si tout se passe bien le serveur DNS est fonctionnelle, on peut le tester avec dig @192.168.0.201 google.fr - remplacer 192.168.0.201 par IP de votre VM - depuis la machine hôte. Pour voir les logs sudo journalctl -u coredns -f dans la VM.

Maintenant comment ajouter la configuration qui permet d'associer IP à nom_du_service.test-nas.local

Pour ce qui est des variables, on les place dans un fichier vars.nix:

{
  ip = "192.168.0.201";
  base_host = "test-nas.local";
}

Puis on modifie coredns.nix :

{ config, pkgs, ...}:
let
  vars = import ./vars.nix;
in
{
    networking.firewall.allowedUDPPorts= [ 53 ];

    # on crée le fichier avec la configuration de la reponce dns
    environment.etc."dns.db".text = ''
      $TTL 3600
      @   IN  SOA ns1.${vars.base_host}. admin.${vars.base_host}. (
              2023101001 ; Serial
              3600       ; Refresh
              1800       ; Retry
              604800     ; Expire
              86400      ; Minimum TTL
      )
      ;
      @    IN  NS  ns1.${vars.base_host}.
      ns   IN  A ${vars.ip}
      *    IN  A ${vars.ip}
    '';

    services.coredns= {
      enable = true;
      extraArgs = [
        "-dns.port=53"
      ];

      config = ''
        . {
            errors
            health
            ready
            forward . /etc/resolv.conf
            cache 30
            loop
            reload
            loadbalance
            log
          }
          # on ajoute ici la configuration
          ${vars.base_host}:53 {
            file /etc/dns.db
            log
            errors
          }
         '';
    };
}

On rebuild la configuration sudo nixos-rebuild switch dans la VM et on teste sûr sur l'hôte avec dig @192.168.0.201 toto.test-nas.local

Après, il ne reste qu'à modifier sa box internet pour qui fournisse ip de notre nas comme serveur DNS. Pensée à garder les anciens en secondaires, au cas où votre nas n'est pas disponible. D'autre solution, est de modifier la configuration réseau sur les pc qui connecte sur le nas.

Enfin parmi le problème que j'ai rencontré est que le serveur DHCP de ma box fournie une adresse DNS en ipV6. Pour que notre serveur DNS soit utilisé, il faut le déactiver.
