Présentation de mon nouveau NAS

Actuellement, je possède un Terramaster F5-221, j'ai changé l'os d'origine par un openmediavault. J'ai ajouté une barrette ram de 8Go, passant à 10Go.

Mon usage principal est la sauvegarde de mes données via borg et SFTP de mes données. J'ai aussi quelques dockers pour des applications comme nextcloud pour la sauvegarde de mes applications.

Comme défaut, que je trouve à configuration actuelle, le manque de performance du CPU. Autre point que j'aimerais changer serais d'avoir un système d'utilisateur unique entre les applications, les partage SFTP que j'utilise.

Je vais changer de nas, j'ai choisi une configuration à base carte mère mini-itx.

Comme on peut voire le CPU est annoncé comme 4.5 plus puissant, je vais tester.

Maintenant, il faut choisir OS, je pourrais rester sur openmediavault, il est bien, mais je m'oriente quelle chose de plus personnaliser. J'ai choisi NixOS comme os de base et Kubernetes pour les applications.
Pourquoi ce choix :

  • Apprendre, oui sur ce projet, je souhaite apprendre et tester de nouvelles choses.
  • Le choix de NixOS, plus que des distributions classiques, c'est pour son côté déclaratif. Toute la configuration de base se trouve dans un ensemble de fichier. Un Os que j'ai utilisé pendant un certain temps sur mon pc personnel.
  • Le choix de Kubernetes, je ne connaissais pas avant, c'est utilisé au travail, il m'est arrivé de faire des petites retouches, mais cela resté superficiel.

Je pourrais utiliser les services fournis par NixOS, Mais c'est l'occasion d'apprendre à utiliser Kubernetes.
